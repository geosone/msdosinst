                    MS-DOS 7.1 - Lizenzhinweis
                    ==========================

MS-DOS und Windows sind Software der Microsoft Corporation und
urheberrechtlich geschützt. Für die Programme auf diesen Disketten
gelten die Lizenzbedingungen von Microsoft (EULA) des Produkts, aus
dem sie stammen (Windows ME, Windows 98 Second Edition, Windows 95,
MS-DOS 6.22).

Sie dürfen diesen Diskettensatz nur verwenden, wenn Sie eine gültige
Lizenz für dieses Produkt besitzen. Mit "Annehmen" bestätigen Sie,
dass Sie die Lizenzbedingungen von Microsoft für dieses Produkt
anerkennen und einhalten. Die Lizenzbedingungen von Windows ME,
Windows 98 SE, Windows 95 und MS-DOS 6.22 folgen auf den nächsten
Seiten.

Disketten erstellt. Er enthält keine Dateien des GeosOne-Projekts
