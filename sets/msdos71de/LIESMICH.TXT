MS-DOS 7.1 - Setup mit dem GeosOne DOS Installer
================================================

Installation
------------

1. Vom Setup-Diskette 1 starten. Das Setup startet automatisch.
2. Gibt es noch kein Laufwerk C:, startet FDISK: eine primäre
   DOS-Partition anlegen und aktivieren, FDISK verlassen. Der
   Computer startet neu, das Setup geht weiter.
3. Ist C: nicht formatiert, formatiert das Setup das Laufwerk.
4. Das Setup überträgt das System (SYS C:), kopiert MS-DOS nach
   C:\DOS (die übrigen Disketten werden angefordert) und legt
   CONFIG.SYS und AUTOEXEC.BAT neu an. Vorhandene Dateien bleiben
   als CONFIG.G01, AUTOEXEC.G01 erhalten.
5. Danach können Sie weitere Software installieren: Diskette mit
   einer INSTALL.INI einlegen (z. B. AHCIASPI, EUSBASPI) und
   "Installieren" wählen.

Programme
---------

MS-DOS 7.1 aus Windows 98 SE mit den neuesten MS-DOS-Programmen aus
Windows ME (FDISK und FORMAT zeigen auch Festplatten über 64 GB
richtig an), dazu die Programme von MS-DOS 6.22, die es in Windows
98/ME nicht mehr gibt (EXPAND, POWER, SHARE für Windows 3.x).

Optionen
--------

  HIMEM.SYS, EMM386.EXE        Speicherverwaltung (EMM386 ohne EMS)
  Deutsche Tastatur            KEYB GR und COUNTRY=049
  MS-DOS Shell                 DOSSHELL (VGA)
  MS-DOS 5.0/6.22-Programme    EDLIN, BACKUP, COMP, MIRROR, ...
  Zusatzprogramme Windows 95   MEMMAKER, MSBACKUP, INTERLNK, ...
  AccessDOS, Tastatur-Utilities, DRVBOOT, Netzwerkdateien
                               von der MS-DOS 6.22-Zusatzdiskette

Erstellt mit mkdosset.ps1: https://github.com/geosone/msdosinst
